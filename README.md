# AI-UI-Template-Collection

A collection of modern AI and SaaS UI templates created using HTML, CSS and JavaScript.

## 📌 Project Overview

This project is a UI Template Collection Hackathon project developed as a team.

The project demonstrates modern web interface designs inspired by popular AI, analytics, SaaS billing, and account management applications.

The main objective is to create responsive and interactive UI templates while demonstrating real-world GitHub collaboration practices.

🔄 GitHub Collaboration Workflow

The team followed the GitHub collaboration workflow:

Fork
  ↓
Clone
  ↓
Branch
  ↓
Develop
  ↓
Commit
  ↓
Push
  ↓
Pull Request
  ↓
Code Review
  ↓
Merge

Each team member worked on a separate branch and submitted their work through Pull Requests.

The Pull Requests were reviewed and approved before being merged into the main branch.



🚀 How to Run
Clone the repository.
Open the required application folder.
Open index.html in a web browser.
Navigate through the available pages and interactions.

Example:

sanjana-ai-chat/chatgpt/index.html
